# Colored Tajwid Fonts

Coloured tajwid fonts is developed from the base font files provided by the KFGQPC. The colouring method was based on the Mushaf than have been approved by the **KDN** (Ministry of Home Affairs Malaysia).

This project is work-in-progress.
